<h2 id="7.4">7.4 Execution procedure of IPL (Normal boot mode)</h2>

This chapter explains how to executing IPL with Normal boot mode.
Normal boot mode provides a device boot process that jumps to an application after initializing the device.

In this mode, when an FSP application is updated, it must be written to the serial flash memory.
However, as the number of writes to the serial NAND flash memory increases, memory degradation will occur, resulting in blocks that cannot be accessed correctly.
When debugging an FSP application in a serial NAND flash memory environment, it is recommended that you use Only init device mode.

The procedure for executing IPL and FSP application is shown below.  
This explanation is a procedure for the RZ/A3UL SMARC Board (QSPI version).  
The explanation uses the project created in <a href="06. IPL build environment construction procedure.md#.6">Chapter 6</a> for this board.  
If you create a Debug configuration for other board, replace your environment with the ones used in this chapter.  
Also, the procedure is the same for both Windows 10 version and Ubuntu 22.04 LTS version.

1. Follow the steps in <a href="06. IPL build environment construction procedure.md#.6">Chapter 6</a> to build the IPL project.
   Be sure to specify "ONLY_INIT_DEVICE=0" as a make option when building to run in Normal boot mode.  
2. Write the generated Motorola S format file of IPL to the Serial Flash memory.  
   The writing method varies depending on the Serial Flash memory you are writing to.  
   See below for writing methods.  
   
   When using flash memory other than NAND Flash memory:<br>
   <a href="08.01.01 How to write IPL to Serial Flash memory using e2studio.md#8.1.1">chapter 8.1.1</a>

   When using NAND Flash memory:<br>
   <a href="08.01.02.01 How to write IPL to Serial Flash memory using Flashwriter for Windows 10.md#8.1.2.1">Chapter 8.1.2.1 (for Windows 10)</a>  
   <a href="08.01.02.02 How to write IPL to Serial Flash memory using Flashwriter for Ubuntu 22.04 LTS.md#8.1.2.2">Chapter 8.1.2.2 (for Ubuntu 22.04 LTS)</a>

3. Build the FSP application that IPL will boot.
   For how to build it, please refer to "Getting Started with RZ/A Flexible Software Package (R01AN6499EJ)".
4. Write the generated srec file of FSP application to the Serial Flash memory.
   The writing method varies depending on the Serial Flash memory you are writing to.
   See below for writing methods.

   When using flash memory other than NAND Flash memory:<br>
   <a href="08.02.01 How to write FSP application to Serial Flash memory using e2studio.md#8.2.1">Chapter 8.2.1</a>

   When using NAND Flash memory:<br>
   <a href="08.02.02.01 How to write FSP application to Serial Flash memory using Flashwriter for Windows 10.md#8.2.2.1">Chapter 8.2.2.1 (for Windows 10)</a>  
   <a href="08.02.02.02 How to write FSP application to Serial Flash memory using Flashwriter for Ubuntu 22.04 LTS.md#8.2.2.2">Chapter 8.2.2.2 (for Ubuntu 22.04 LTS)</a>

5. Set the RZ/A3UL SMARC EVK board operating mode to Boot Mode3 (1.8-V Serial Flash Memory) and turn on the power.
6. At this time, the log shown in <a href="#Figure7.4.1">Figure 7.4.1</a> is displayed on Serial Terminal.  
   In addition, the program written in the Serial Flash memory starts and the LED of the RZ/A3UL SMARC EVK board blinks as shown in <a href="#Figure7.4.2">Figure 7.4.2</a>.
