<h3 id="4.11.2.3">4.11.2.3 Variables for Serial Flash memory (MX25L25645Q)</h3>

This chapter describes the variables that store the API functions and operations for controlling the MX25L25645Q.<br>
<a href="#Table4.63">Table 4.63</a> shows a list of these variables.

| Variable Name | Description | Detail |
