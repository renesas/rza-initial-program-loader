<h3 id="4.12.2.3">4.12.2.3 Serial Flash Memory driver / OctaFlash driver API functions</h3>

This chapter shows the API functions to call the Serial Flash Memory Driver / OctaFlash Driver.<br>
Functions of Serial NOR Flash memory driver / Serial NAND Flash memory driver / OctaFlash driver are called through these API functions.

<th colspan="2">flash_erase</th>
</tr>
</thead>
<tbody>
<tr>
<td>Outline</td>
<td>Erase the Serial Flash Memory driver / OctaFlash</td>
</tr>
<tr>
<td>Declaration</td>
<td>int flash_erase (xspidevice_ctrl_t * ctrl, size_t address, size_t length)</td>
</tr>
<tr>
<td>Description</td>
<td><p>Data erase the Serial Flash Memory driver / OctaFlash.<br>
Data erase is performed with addresses and sizes in units of 4-Kbytes.</p></td>
</tr>
<tr>
<td>Arguments</td>
<td><p>*ctrl : Pointer to the control structure for instance<br>
address : Start address for data erase<br>
&emsp;&emsp;&emsp;&emsp;Specify the offset address in the Serial Flash Memory driver / OctaFlash for this argument.<br>
&emsp;&emsp;&emsp;&emsp;If a value other than a multiple of 4-Kbytes is set, the address obtained by aligning the specified address with 4-Kbytes will be the start address of the 
erase area.<br>
length : erase size<br>
&emsp;&emsp;&emsp;&emsp;If a value other than 4-Kbyte aligned size is set in this argument, it erases the data up to the 4-Kbyte aligned address including the specified range.</p></td>
</tr>
<tr>
<td>Return value</td>
<td><p>0 : Data erase is success<br>
-1 : Data erase is failed.</p></td>
</tr>
</tbody>
