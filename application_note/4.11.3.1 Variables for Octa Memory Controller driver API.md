<h3 id="4.11.3.1">4.11.3.1 Variables for Octa Memory Controller driver API</h3>

<a href="#Table4.75">Table 4.75</a> shows the variables that manage the function of the Octa Memory Controller driver.

<h4 id="Table4.75">Table 4.75 Octa Memory Controller driver API function table (octa_api)</h4>

| Member | Setting value | Description |
|----|----|----|
| open | octa_open | Octa Memory Controller driver open function |
| close | octa_close | Octa Memory Controller driver close function |
| post_init | octa_post_init | Octa Memory Controller driver post initialization function |
| exec_op | octa_exec_op | Octa Memory Controller driver operation function |
| configure_xip | octa_configure_xip | Octa Memory Controller driver Memory-map Mode setting function |
| start_xip | octa_start_xip | Octa Memory Controller driver Memory-map Mode start function |
| stop_xip | octa_stop_xip | Octa Memory Controller driver Memory-map Mode stop function |
| run_manual_calibration | octa_run_manual_calibration | Octa Memory Controller driver manual calibration function |
| enable_auto_calibration | octa_enable_auto_calibration | Octa Memory Controller driver auto calibration enable function |
| disable_auto_calibration | octa_disable_auto_calibration | Octa Memory Controller driver auto calibration disable function |
| set_frequency | octa_set_frequency | Octa Memory Controller driver operation frequency setting function |
| clean_mmap | octa_clean_mmap | Octa Memory Controller driver cache clean function |
| inv_mmap | octa_inv_mmap | Octa Memory Controller driver cache invalid function |
| get_mmap_base | octa_get_mmap_base | Octa Memory Controller driver memory map region address get function |
| get_mmap_size | octa_get_mmap_size | Octa Memory Controller driver memory map region size get function |
