<h2 id="1.2">1.2 IPL processing overview</h2>

The outline of IPL processing is described below.

1. Release the reset and supply the clock to the module used for the boot process.
2. Initialize the serial communication interface for debug message output and control the message input/output.
3. Change the settings of SPI Multi I/O Bus Controller or Octa Memory Controller.
4. Initialize DDR SDRAM.
5. Copy the FSP Application image from Flash memory to DDR SDRAM.
6. Jump to the entry point of FSP Application on DDR SDRAM.
