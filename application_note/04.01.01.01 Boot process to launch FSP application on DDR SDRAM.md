<h3 id="4.1.1.1">4.1.1.1 Boot process to launch FSP application on DDR SDRAM</h3>

<a href="#Figure4.1.1.1.1">Figure 4.1.1.1.1</a> shows an operation image when an FSP application written to Serial NOR Flash memory is loaded into DDR SDRAM and executed.

![](image/Figure4.1.1.1.1.png)

<center><h4 id="Figure4.1.1.1.1">Figure 4.1.1.1.1 Operation image when launching an FSP application on DDR SDRAM (Serial NOR Flash memory)</h4></center>

Describes IPL boot process on the RZ/A3UL SMARC EVK board.

1. RZ/A3UL executes the BootROM program after releasing the power-on reset.
2. When the RZ/A3UL operating mode is Boot mode 3, the BootROM program will enable SPIBSC and initialize it.  
   The initial setting is that it can access independently of the model of the Serial NOR Flash memory.
3. The BootROM program reads IPL stored in the start address (\*1) of the Serial NOR Flash memory and copies IPL to the entry point address (\*2) on the On-chip RAM.  
   Then SPIBSC is reset by BootROM, and access to the Serial NOR Flash memory will be prohibited.
4. The BootROM program jumps to IPL entry point on the On-chip RAM.
5. IPL initializes MEMC and controls the initial setting of DDR SDRAM.
6. Initialize the DDR SDRAM by controlling the initial setting of MEMC.
7. IPL makes additional pin settings and resets SPIBSC for 4-byte access to the Serial NOR Flash memory and changes the settings to the optimum settings for the Serial NOR Flash memory (AT25QL128A) mounted on the RZ/A3UL SMARC EVK board.
8. A command is issued via SPIBSC to Serial NOR Flash memory to change the settings for memory.
9. IPL reads the application header.
10. IPL will copy the FSP application to DDR SDRAM according to the contents of the application header.
11. IPL follows the contents of the application header and jumps to the entry point of the FSP application on DDR SDRAM.

    (\*1) This address will be H'2000_0000 when the external address space read mode is set.  
    (\*2) IPL entry point address is H'0001_2000.

Describes IPL boot process on the EK-RZ/A3M.

1. RZ/A3M executes the BootROM program after releasing the power-on reset.
2. When the RZ/A3M operating mode is Boot mode 7, the BootROM program will enable SPIBSC and initialize it.  
   The initial setting is that it can access independently of the model of the Serial NAND Flash memory.
3. The BootROM program reads IPL stored in the start address (\*1) of the Serial NAND Flash memory and copies IPL to the entry point address (\*2) on the On-chip RAM.  
   Then SPIBSC is reset by BootROM, and access to the Serial NAND Flash memory will be prohibited.
4. The BootROM program jumps to IPL entry point on the On-chip RAM.
5. IPL initializes MEMC and controls the initial setting of DDR SDRAM.
6. Initialize the DDR SDRAM by controlling the initial setting of MEMC.
7. IPL makes additional pin settings and resets SPIBSC for 4-byte access to the Serial NAND Flash memory and changes the settings to the optimum settings for the Serial NAND Flash memory (W25N01GV) mounted on the EK-RZ/A3M board.
8. A command is issued via SPIBSC to Serial NAND Flash memory to change the settings for memory.
9. IPL reads the application header.
10. IPL will copy the FSP application to DDR SDRAM according to the contents of the application header.  
    At this time, FSP application data that is aligned to the block size is copied by the DMAC, and unaligned data is copied by the CPU.  
11. IPL follows the contents of the application header and jumps to the entry point of the FSP application on DDR SDRAM.

    (\*1) This address will be H'2000_0000 when the external address space read mode is set.  
    (\*2) IPL entry point address is H'0001_2000.
