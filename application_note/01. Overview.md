<h2 id="1.">1. Overview</h2>

IPL is a boot program for RZ/A3 devices.

When starting the RZ/A3 device, IPL initializes the peripheral I/O modules, the memory installed on the board, etc., and launches the FSP application.

IPL consists of functions such as peripheral I/O module driver, memory control driver, and FSP application image load module.
