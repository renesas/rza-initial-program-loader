<h2 id="8.3">8.3 How to change IPL build environment for custom board</h2>

This chapter describes the procedure for creating an IPL build environment for boards that are not supported by the default IPL (hereafter referred to as custom board).

IPL build environment for custom board is created by modifying the build environment for RZ/A3UL SMARC EVK board.  
The chapters listed below will show you how to do that.

* How to customize IPL for your Serial Flash memory (<a href="8.3.1 How to customize IPL for your Serial Flash memory.md#8.3.1">Chapter 8.3.1</a>)  
* Specifications of functions that control Serial Flash memory and how to change functions when memory is changed (<a href="8.3.1.1 flash_open.md#8.3.1.1">Chapter 8.3.1.1</a> to <a href="8.3.1.14 flash_erase_4k_flash_erase_32k_flash_erase_64k.md#8.3.1.14">Chapter 8.3.1.14</a>)  
* How to add settings for custom board to IPL (<a href="8.3.2 How to add a setting for a board on which your Serial Flash memory is mounted.md#8.3.2">Chapter 8.3.2</a>)  
* How to add clock supply settings for mounted modules (<a href="8.3.3 How to add a Module for Clock Supply.md#8.3.3">Chapter 8.3.3</a>)  
* How to add pin settings (<a href="8.3.4 How to add pin setting.md#8.3.4">Chapter 8.3.4</a>)  
* How to add MMU settings (<a href="8.3.5 How to change MMU setting.md#8.3.5">Chapter 8.3.5</a>)
