<h2 id="7.3.1">7.3.1 Setting for Windows 10</h2>

This chapter describes the procedure for setting the serial terminal fow Windows 10.  

1. Power on the target board.  
2. Launch Tera Term.  
3. Click [File] -> [New connection].

   <center><img src="image/Figure7.3.1.1.png"  width="75%"></center>

   <center><h4 id="Figure7.3.1.1">Figure 7.3.1.1 Connection setting</h4></center>
  

4. Select the serial connection port for the target board in the Serial field. 
   The name of the serial connection port will vary depending on the target board, as shown below. 
   The COM number will vary depending on your Windows 10 PC environment.

   For the RZ/A3UL SMARC EVK board (QSPI version / Octal-SPI version):<br>
   USB Serial Port

   For the EK-RZ/A3M board:<br>
   JLink CDC UART Port

   <center><img src="image/Figure7.3.1.2.png"  width="60%"></center>

   <center><h4 id="Figure7.3.1.2">Figure 7.3.1.2 Serial Port (RZ/A3UL SMARC EVK board)</h4></center>
  
   <center><img src="image/Figure7.3.1.3.png"  width="60%"></center>

   <center><h4 id="Figure7.3.1.3">Figure 7.3.1.3 Serial Port (EK-RZ/A3M board)</h4></center>

5. Return to the main screen, click [Setup] -> [Serial port].  

   <center><img src="image/Figure7.3.1.4.png"  width="75%"></center>

   <center><h4 id="Figure7.3.1.4">Figure 7.3.1.4 Serial port setting</h4></center>
  
  
6. Configure the serial port as shown below:

   Speed: 115200<br>
   Data: 8 bit<br>
   Parity: none<br>
   Stop bits: 1bit 
   Flow control: none <br>
   Transmit delay: 0msec/char, 0msec/line 

   After completing the settings, click [New setting] to reflect the changes.

   <center><img src="image/Figure7.3.1.5.png"  width="60%"></center>

   <center><h4 id="Figure7.3.1.5">Figure 7.3.1.5 Serial port setting</h4></center>
