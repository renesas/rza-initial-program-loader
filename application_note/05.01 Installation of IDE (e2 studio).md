<h2 id="5.1">5.1 Installation of IDE (e<sup>2</sup> studio)</h2>

IPL uses e<sup>2</sup> studio as the development environment.
This chapter shows you how to install it.

Please download the e<sup>2</sup> studio installer from the Renesas Electronics web page below.  
The toolchain does not need to be downloaded because it is included in the e<sup>2</sup> studio installer and will be installed during the e<sup>2</sup> studio installation.

<https://www.renesas.com/software-tool/e-studio>

RZ FSP (Flexible Software package) packs are required to build an IPL execution environment in e<sup>2</sup> studio.  
Please follow the instructions on the website below to download it.

<https://www.renesas.com/software-tool/rz-flexible-software-package-fsp>
