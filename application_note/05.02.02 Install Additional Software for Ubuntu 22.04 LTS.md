<h3 id="5.2.2">5.2.2 Install Additional Software for Ubuntu 22.04 LTS</h3>

You must install some additional software to build IPL in Ubuntu 22.04 LTS.

Install libncurses5:  
1.  Execute the following command to install libncurses5.
    ```
    $ sudo apt-get install libncurses5 libncurses5:i386
    ```
Install J-Link driver:  
1.  Download the Segger J-Link driver file from the "Linux" -> "64-bit DEB installer" link on the following website.

    <https://www.segger.com/downloads/jlink/>

2.  Execute the following command to install driver file.  
    The command is an example when the name of the driver file is "JLink_Linux_V810a_x86_64.deb".  
    Change the argument according to the file name.
    ```
    $ sudo dpkg -i JLink_Linux_V810a_x86_64.deb
    ```
    If you get unmet dependencies error, please do the following.
    ```
    $ sudo apt-get -f install
    $ sudo dpkg -i JLink_Linux_v810a_x86_64.deb
    ```
Install libpython3.10:  
1.  If your PC does not have libpython3.10 installed, install it.
    ```
    $ sudo apt-get install libpython3.10
    ```
Install minicom:  
1.  If your PC does not have minicom installed, install it.
    ```
    $ sudo apt install minicom
    ```
2.  If the brltty application is installed on Ubuntu, the serial USB will be disconnected.<br>
Therefore, disable the settings for this application.<br>
Open 85-brltty.rules.
    ```
    $ sudo vim /usr/lib/udev/rules.d/85-brltty.rules
    ```
3.  Comment out the following statement in this file:
    ```
    ENV{PRODUCT}=="1a86/7523/*", ENV{BRLTTY_BRAILLE_DRIVER}="bm", GOTO="brltty_usb_run"
    ```
4.  Reboot the system to make the changes effective.
    ```
    sudo reboot now
    ```    
    Note:  
    minicom will be used to receive messages from the target board and transfer files to the target board.  
    Please download Flash Writer from the link below.  
    <https://www.renesas.com/ja/products/rz-a3m>
