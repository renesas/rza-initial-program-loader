<h2 id="4.1">4.1 Operation overview</h2>

This chapter describes the case where the RZ/A3 device is booted from flash memory as an example of the boot process.
Depending on the memory installed on the board and the memory on which the FSP application is running, the boot process varies.
This document shows four examples of the boot process for the RZ/A3UL

* When the Serial Flash memory is installed on the board and the FSP Application runs on the DDR SDRAM (<a href="4.1.1.1 Boot process to launch FSP application on DDR SDRAM.md#4.1.1.1">Chapter 4.1.1.1</a>)
* When the Serial Flash memory is installed on the board and the FSP Application runs on the Serial Flash memory (<a href="4.1.1.2 Boot process to launch FSP application on Serial Flash memory.md#4.1.1.2">Chapter 4.1.1.2</a>)
* When the OctaFlash memory is installed on the board and the FSP Application runs on the OctaRAM (<a href="4.1.2.1 Boot process to launch FSP application on OctaRAM.md#4.1.2.1">Chapter 4.1.2.1</a>)
* When the OctaFlash memory is installed on the board and the FSP Application runs on the OctaFlash memory (<a href="4.1.2.2 Boot process to launch FSP application on OctaFlash memory.md#4.1.2.2">Chapter 4.1.2.2</a>)
