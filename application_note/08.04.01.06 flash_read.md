<h3 id="8.4.1.6">8.4.1.6 flash_read</h3>

flash_read() is a function to read data from Serial Flash memory.

In IPL, Serial Flash memory operates in External Space Address Read Mode.  
Therefore, flash_read() implemented in the default IPL directly reads data from the space where Serial Flash memory is mapped (0x20000000 or later) without serial communication processing of the Read operation.
