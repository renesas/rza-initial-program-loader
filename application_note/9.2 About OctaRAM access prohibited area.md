<h3 id="9.2">9.2 About OctaRAM access prohibited area</h3>

Test data for OctaRAM initialization is stored in the OctaRAM area shown below.  
If you overwrite the test data, you may not be able to access OctaRAM correctly.  
Therefore, access to this area is prohibited.

* Access prohibited address:
* 0x28000000 - 0x2800000F
