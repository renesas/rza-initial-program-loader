<h3 id="4.2.4">4.2.4 Settings of Octa Memory Controller Register when using OctaFlash memory</h3>

<a href="#Table4.4">Table 4.4</a> shows the Octa Memory Controller register settings after the OctaFlash memory initial settings are completed.

These setting values include the results that reflect the settings described in the Octa Memory Controller section in <a href="4.2.3 Peripheral Function Setting when using OctaFlash memory.md#Table4.3">Table 4.3</a> Peripheral Function Settings.
