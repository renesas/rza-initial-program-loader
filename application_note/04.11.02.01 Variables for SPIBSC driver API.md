<h3 id="4.11.2.1">4.11.2.1 Variables for SPIBSC driver API</h3>

<a href="#Table4.11.2.1.1">Table 4.11.2.1.1</a> shows the variables that manage the function of SPIBSC driver.

<h4 id="Table4.11.2.1.1">Table 4.11.2.1.1 SPIBSC driver API function table (spim_api)</h4>

| Member | Setting value | Description |
|----|----|----|
| open | spim_open | SPIBSC driver open function |
| close | spim_close | SPIBSC driver close function |
| post_init | spim_post_init | SPIBSC driver post initialization function |
| exec_op | spim_exec_op | SPIBSC driver operation function |
| configure_xip | spim_configure_xip | SPIBSC driver External Space Address Read Mode setting function |
| start_xip | spim_start_xip | SPIBSC driver External Space Address Read Mode start function |
| stop_xip | spim_stop_xip | SPIBSC driver External Space Address Read Mode stop function |
| run_manual_calibration | spim_run_manual_calibration | SPIBSC driver manual calibration function |
| enable_auto_calibration | spim_enable_auto_calibration | SPIBSC driver auto calibration enable function |
| disable_auto_calibration | spim_disable_auto_calibration | SPIBSC driver auto calibration disable function |
| set_frequency | spim_set_frequency | SPIBSC driver operation frequency setting function |
| clean_mmap | spim_clean_mmap | SPIBSC driver cache clean function |
| inv_mmap | spim_inv_mmap | SPIBSC driver cache invalid function |
| get_mmap_base | spim_get_mmap_base | SPIBSC driver memory map region address get function |
| get_mmap_size | spim_get_mmap_size | SPIBSC driver memory map region size get function |
