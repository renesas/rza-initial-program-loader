<h3 id="4.1.3">4.1.3 Wait routine when debug mode is enabled</h3>

This section describes the wait routine executed when debug mode is enabled.<br>
This process is intended to provide sufficient time for downloading FSP applications during development, and the wait duration can be adjusted by the user.

## Overview

IPL includes a wait routine intended to provide sufficient time for downloading FSP applications during development.<br>
This process is executed only when debug mode is enabled. When debug mode is disabled, the wait routine is skipped and IPL proceeds with the normal boot sequence.<br>
The wait routine is performed during application loading by executing a software delay loop.

## Wait routine settings

The following information describes the implementation and configuration of the wait routine.

**Source file**<br>
<code>bl2/aarch64/bl2_el3_entrypoint.S</code>

**Loop label**<br>
<code>wait_loop</code>

**Loop count macros**<br>
<code>WAIT_CNT_HIGH16</code>, <code>WAIT_CNT_LOW16</code>

**Default wait count**<br>
<code>0x01000000</code>

The wait count is defined as a 32-bit value using the <code>WAIT_CNT_HIGH16</code> and <code>WAIT_CNT_LOW16</code> macros.<br>
The upper 16 bits of the wait count are specified by <code>WAIT_CNT_HIGH16</code>, and the lower 16 bits are specified by <code>WAIT_CNT_LOW16</code>. These values are combined to form the final 32-bit wait count used by the wait loop.<br>
For example, when <code>WAIT_CNT_HIGH16</code> is set to <code>0x0100</code> and <code>WAIT_CNT_LOW16</code> is set to <code>0x0000</code>, the resulting wait count is <code>0x01000000</code>.<br>

## Wait routine customization

The delay duration is determined by the value specified by the loop count macros.<br>
The amount of time required for downloading an FSP application may vary depending on the development environment and tools being used. Therefore, the wait duration can be adjusted by the user.<br>
If additional time is required for application download operations, adjust the wait duration by modifying the value of the loop count macros.<br>
Increasing the value of the loop count macros provides additional time for application download operations. However, it also increases the startup time when debug mode is enabled.<br>
After modifying the setting, verify that application download operations work correctly in the target development environment.
