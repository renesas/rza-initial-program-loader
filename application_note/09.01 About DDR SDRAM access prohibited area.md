<h3 id="9.1">9.1 About DDR SDRAM access prohibited area</h3>

Test data for DDR SDRAM initialization is stored in the DDR SDRAM area shown below.  
If you overwrite the test data, you may not be able to access DDR SDRAM correctly.  
Therefore, access to this area is prohibited.

* Access prohibited address:
* RZ/A3UL: 0x40000000 - 0x4000003F
* RZ/A3M: 0x40000000 - 0x4000001F
