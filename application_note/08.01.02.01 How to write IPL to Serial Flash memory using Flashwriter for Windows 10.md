<h2 id="8.1.2.1">8.1.2.1 How to write IPL to Serial Flash memory using Flashwriter for Windows 10</h2>

This is an explanation of the procedure for writing an IPL to the EK-RZ/A3M Kit when using Tera Term as a serial terminal in Windows 10.

The explanation uses the project created in <a href="06. IPL build environment construction procedure.md#.6">Chapter 6</a> for this board.  
If you create a Debug configuration for other board, replace your environment with the ones used in this chapter. 

1. Set the EK-RZ/A3M main board operating mode to Boot Mode5 (SCIF download mode) and turn on the power.  
2. When the following message appears on Tera Term, drag and drop Flashwriter.

   <center><img src="image/Figure8.1.2.1.1.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.1">Figure 8.1.2.1.1 Tera Term screen (1)</h4></center>

3. After Flash Writer starts, enter the SUP command.

   <center><img src="image/Figure8.1.2.1.2.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.2">Figure 8.1.2.1.2 Tera Term screen (2)</h4></center>

4. After that, when "Scif Speed UP" is displayed on the teardown, click Setup->Serial port.
   Then, on the Serial port setup and connection screen that appears, change the Speed to [921600] and click [New setting].
   When you return to the Tera Term main screen, press the Enter key.

   <center><img src="image/Figure8.1.2.1.3.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.3">Figure 8.1.2.1.3 Tera Term screen (3)</h4></center>

   <center><img src="image/Figure8.1.2.1.4.png"  width="60%"></center>

   <center><h4 id="Figure8.1.2.1.4">Figure 8.1.2.1.4 Select Speed (1)</h4></center>

5. Execute the "NAND_XLS2T" command.
   Enter "y" for "OK?(y/n)".

   <center><img src="image/Figure8.1.2.1.5.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.5">Figure 8.1.2.1.5 Tera Term screen (4)</h4></center>

6. When "Please input Program Top Address" is displayed on Tera Term, enter "20000000" and press Enter.

   <center><img src="image/Figure8.1.2.1.6.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.6">Figure 8.1.2.1.6 Tera Term screen (5)</h4></center>

7. When "Please input Qspi Save Address" is displayed on Tera Term, enter "0" and press Enter.

   <center><img src="image/Figure8.1.2.1.7.png"  width="80%"></center>

   <center><h4 id="Figure8.1.2.1.7">Figure 8.1.2.1.7 Tera Term screen (6)</h4></center>

8. When "please send!" is displayed on Tera Term, drag and drop "rza3m_ek_nand_ipl.srec".

   <center><img src="image/Figure8.1.2.1.8.png"  width="75%"></center>

   <center><h4 id="Figure8.1.2.1.8">Figure 8.1.2.1.8 Tera Term screen (7)</h4></center>

9. Then, the IPL will be written to the NAND Flash memory, and "complete!:spi_nand_Close" will be displayed on Tera Term.

   <center><img src="image/Figure8.1.2.1.9.png"  width="75%"></center>

   <center><h4 id="Figure8.1.2.1.9">Figure 8.1.2.1.9 Tera Term screen (7)</h4></center>

10. Follow the same steps as in step 4 to bring up the Serial port setup and connection screen.
    Then change the Speed to [115200].

   <center><img src="image/Figure8.1.2.1.10.png"  width="60%"></center>

   <center><h4 id="Figure8.1.2.1.10">Figure 8.1.2.1.10 Select speed (2)</h4></center>

11. Set the EK-RZ/A3M main board operating mode to Boot Mode7 (3.3-V Serial NAND Flash Memory) and reset the power.  
    At this time, IPL startup messages (<a href="#Figure8.1.2.1.11">Figure 8.1.2.1.11</a>) are output to the serial terminal.   
    
    The IPL behavior after the IPL startup messages are output varies depending on the operating mode and whether the FSP application has been written to the serial flash memory.

   <center><img src="image/Figure8.1.2.1.11.png"  width="60%"></center>

   <center><h4 id="Figure8.1.2.1.11">Figure.8.1.2.11 IPL startup messages</h4></center>
