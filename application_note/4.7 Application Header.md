<h2 id="4.7">4.7 Application Header</h2>

IPL obtains the save address, copy destination address and entry point of the FSP Application image according to the application header written to the Serial Flash memory, copies the image, and jumps to the FSP Application.

IPL loads the application header from the address set in "FSP_BASE" in the make option.  
Write the application header in advance in the format shown in the figure from the address set in "FSP_BASE" before executing IPL.  
If "FSP_BASE" is not specified in the make command, H'2002_0000 is set as the default value. The header structure is shown below.
