<h3 id="4.12.2.2">4.12.2.2 SPIBSC driver functions</h3>

SPIBSC driver functions that control SPIBSC are shown below.

| xspi_setup |  |
|----|----|
| Outline | Initialize the Serial Flash memory |
| Declaration | void xspi_setup (void) |
| Description | This function calls the API function corresponding to the Serial Flash memory and initializes the memory. |
| Arguments | None |
| Return value | None |

<tbody>
<tr>
<td>Outline</td>
<td>Get the operation format supported by SPIBSC driver</td>
</tr>
<tr>
<td>Declaration</td>
<td>uint32_t spim_get_features (xspi_ctrl_t * const ctrl)</td>
</tr>
<tr>
<td>Description</td>
<td>Get the operation format supported by SPIBSC driver</td>
</tr>
<tr>
<td>Arguments</td>
<td>*ctrl : Pointer to the control structure for instance</td>
</tr>
<tr>
<td>Return value</td>
<td><p>Positive number:Returns the OR of the following bit values<br>
&emsp;XSPI_FEATURE_XIP_READ : The driver supports read access.<br>
&emsp;XSPI_FEATURE_XIP_WRITE : The driver supports write access.<br>
&emsp;XSPI_FEATURE_FORM112 : The driver supports 1-1-2 form.<br>
&emsp;XSPI_FEATURE_FORM122 : The driver supports 1-2-2 form.<br>
&emsp;XSPI_FEATURE_FORM222 : The driver supports 2-2-2 form.<br>
&emsp;XSPI_FEATURE_DUAL : The driver supports 1-1-2, 1-2-2, and/or 2-2-2 form(s).<br>
&emsp;XSPI_FEATURE_FORM114 : The driver supports 1-1-4 form.<br>
&emsp;XSPI_FEATURE_FORM144 : The driver supports 1-4-4 form.<br>
&emsp;XSPI_FEATURE_FORM444 : The driver supports 4-4-4 form.<br>
&emsp;XSPI_FEATURE_QUAD : The driver supports 1-1-4, 1-4-4, and/or 4-4-4 form(s).<br>
&emsp;XSPI_FEATURE_FORM118 : The driver supports 1-1-8 form.<br>
&emsp;XSPI_FEATURE_FORM188 : The driver supports 1-8-8 form.<br>
&emsp;XSPI_FEATURE_FORM888 : The driver supports 8-8-8 form.<br>
&emsp;XSPI_FEATURE_OCTAL : The driver supports 1-1-8, 1-8-8, and/or 8-8-8 form(s).<br>
&emsp;XSPI_FEATURE_DDROP : The driver supports DDR for op code.<br>
&emsp;XSPI_FEATURE_DDR : The driver supports DDR for address and/or data.<br>
&emsp;XSPI_FEATURE_OCTARAM : OctaRAM addressing (RAS/CAS) supported.</td>
</tr>
</tbody>
