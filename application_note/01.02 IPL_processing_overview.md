<h2 id="1.2">1.2 IPL processing overview</h2>

The outline of IPL processing is described below.

1. Release the reset and supply the clock to the module used for the boot process.
2. Initialize the serial communication interface for debug message output and control the message output.
3. Initialize DDR SDRAM.
4. Change the settings of the SPI multi I/O Bus Controller or Octa Memory Controller so that the program on the Flash memory can be executed directly.
5. Get the FSP entry point address from the Application Header.
6. Jump to the entry point of FSP application on the Flash memory.

Note:  
Depending on the FSP application project, the program may be executed on SDRAM.  
In this case, IPL obtains the copy destination address and the entry point address of the FSP application in SDRAM from the <a href="04.07 Application Header.md#4.7">Application Header</a>.  
Then, IPL copies the FSP application to the address obtained from the Application Header and jumps to the entry point.
