<h3 id="5.1.2">5.1.2 Installation of FSP packs</h3>

Install the FSP packs for use in the RZ/A3 IPL environment.  

1. Exit e<sup>2</sup> studio

2. Extract FSP Packs.

3. Copy the extracted FSP Packs (named "internal") to the e<sup>2</sup> studio installation folder as shown below:  

    * For Windows 10 environment:
      " C:\Renesas\e2_studio\internal\projectgen\rz_fsp\packs"
    * For Ubuntu 22.04 LTS environment: "~/.local/share/Renesas/e2_studio/internal/projectgen/rz_fsp/packs"

   The image shows the installation folder when the RZ Flexible Software Package packs are installed.

    <center><img src="image/Figure5.1.2.1.png"></center>

    <center><h4 id="Figure5.1.2.1">Figure 5.1.2.1 Installed packs folder (for RZ Flexible Software Package)</h4></center>

4. Please re-launch e<sup>2</sup> studio  
   Then packs will be reflected in the development environment.
