<h2 id="3.1">3.1 Peripheral Functions used</h2>

IPL uses the peripheral features shown in <a href="#Table3.1">Table 3.1</a>.

<h4 id="Table3.1">Table 3.1 Peripheral functions and uses</h4>

<table>
<colgroup>
<col style="width: 23%" />
<col style="width: 76%" />
</colgroup>
<thead>
<tr>
<th>Peripheral Function</th>
<th>Use</th>
</tr>
</thead>
<tbody>
<tr>
<td>SPI Multi-I/O Bus Controller (SPIBSC)</td>
<td><p>A peripheral function used when IPL controls Serial Flash memory.</p>
<p>Set to External Address Space Read Mode and generate a signal for the CPU to read directly from the Serial Flash memory connected to the SPI multi-I/O bus space.</p>
<p>IPL uses a driver called "SPIBSC driver" to control SPIBSC.</p></td>
</tr>
<tr>
<td>Octa Memory Controller</td>
<td><p>A peripheral function used when IPL controls OctaFlash memory and OctaRAM.</p>
<p>Enable Memory-map Mode (memory-mapped reading and writing) to memory devices in separate flash and RAM.</p>
<p>IPL uses the "Octa Controller Driver" to control the Octa Memory controller.</p></td>
</tr>
<tr>
<td>DDR3L/DDR4 SDRAM Memory Controller (MEMC)</td>
<td>Make settings to access DDR3L/DDR4 SDRAM connected to the external bus space.</p>
</p>Note that RZ/A3M only supports DDR3L SDRAM.</td>
</tr>
<tr>
<td>Clock pulse generator (CPG)</td>
<td><p>Generate the operating frequency of the RZ/A3.</p>
<p>Release the module standby mode of the RZ/A3's peripheral I/O modules.</p></td>
</tr>
<tr>
<td>General Purpose Input Output Port (GPIO)</td>
<td>Switch multiplexed pin functions for SCIFA channel 0 and set the QSPI dedicated pins.</td>
</tr>
<tr>
<td>Serial communication interface with FIFO (SCIFA)</td>
<td>Used for message output to the host PC using SCIFA channel 0.</td>
</tr>
<tr>
<td>System Counter (SYC)</td>
<td>Generate the count value used by the generic timer built into the Cortex&reg;-A55 core.</td>
</tr>
<tr>
<td>Memory Management Unit (MMU)</td>
<td>Generate a translation table that specifies the cache effective area and memory type for the RZ/A address space.</td>
</tr>
<tr>
<td>System Controller (SYSC)</td>
<td><p>System control of this LSI.</p>
<p>Select SPIBSC or Octa Memory controller.</p></td>
</tr>
</tbody>
</table>
