# RZ/A3 Initial Program Loader Application Note

## Introduction

This application note describes the following contents about the reference implementation of Initial Program Loader (called IPL), which is a boot loader for booting user programs from Flash memory (Serial Flash memory or Octa Flash memory) connected to RZ/A3 devices.

* Description of IPL function
* Description of how to build the development environment
* Description of how to debug
* How to customize when supporting Serial Flash memory that is not supported by default IPL

## Target Device

* RZ/A3UL
* RZ/A3M

When using this application note with other Renesas Microprocessors, sufficient evaluation is recommended after making modifications to comply with the alternate Microprocessor.
